consumer trends using a dataset of 50,000 food orders.

📌 Project Overview

This project analyzes food ordering data to identify patterns and trends
related to cities, cuisines, age groups, restaurant segments, meal
types, company types, customer ratings, order value, order volume, and
time taken to order.

The analysis is presented through interactive Tableau visualizations and
a web interface built using Flask.

🎯 Objectives

Analyze food ordering behaviour across different cities and customer
groups.

Understand customer preferences across different cuisines.

Compare orders across age groups and restaurant segments.

Analyze meal-wise revenue contribution.

Study customer ratings across different meal types.

Identify patterns in city-wise order volume.

Present the findings through an interactive dashboard and story.

📊 Key Dashboard Insights

50,000 food orders were analyzed.

Order volumes are relatively balanced across the major cities.

Mumbai and Pune are among the higher-volume cities.

Desserts and Chinese cuisine show strong customer preference based
on order counts.

Gen 2 and Millennial groups contribute a large share of the orders.

Meal types have nearly equal revenue contributions.

Average customer ratings across meal types are close to 3.0.
